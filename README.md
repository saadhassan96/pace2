# pace2

One-page site for the IARSLCE 2026 pre-conference workshop **Participatory AI for Community Engagement** (Sunday, October 11, 2026, Monroe Hall 152, Tulane University).

Put this folder at the root of the saadh.info repo and it is served at https://saadh.info/pace2/.

- `index.html` has all the content: top section, About, Schedule, Organizers, Slides.
- `css/style.css` holds colors and fonts as tokens at the top (light and dark themes).
- `js/site.js` runs the theme switch and highlights the current section in the sticky nav as you scroll.
- `slides.pdf` and `slides.pptx` are linked from the Slides section. Replace them with newer versions using the same names.
